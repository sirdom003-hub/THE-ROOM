# 🌐 THE-ROOM

O **THE-ROOM** é uma aplicação web interativa focada em front-end, projetada para oferecer uma experiência de navegação limpa, moderna e responsiva. O projeto conta com uma estrutura organizada de páginas que incluem ecrãs de login/registo, formulários validados e uma interface dinâmica de chat.

## 🚀 Funcionalidades

* **Página Inicial:** Interface de utilizador moderna e intuitiva para dar as boas-vindas.
* **Formulários:** Fluxo de login e criação de conta (`signup.html`) integrado com validações em JavaScript.
* **Design Responsivo:** Folhas de estilo otimizadas para uma visualização fluida.validações em JavaScript.

## 🛠️ Próximos Passos (Em Desenvolvimento)

O projeto está em fase ativa de evolução. Os objetivos traçados para as próximas etapas são:
- [ ] Concluir a integração da interface do utilizador no ecrã de `chat.html`.
- [ ] Implementar a lógica JavaScript para simular ou gerir o envio de mensagens em tempo real.
- [ ] Finalizar as validações avançadas dos campos de formulário.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as tecnologias fundamentais da web:

* **HTML5:** Estrutura semântica das páginas e formulários.
* **CSS3:** Estilização avançada, layouts modernos e design responsivo (organizado nas pastas `style_css`).
* **JavaScript (ES6+):** Lógica de comportamento, controlo dos formulários e interatividade (organizado na pasta `theroom_js`).
